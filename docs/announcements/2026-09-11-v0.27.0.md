工作台流程升级——自动头部遮罩 · 更安全的数据编辑与训练提交 · LLM 预设独立存储 · LyCORIS v4 兼容基线

### 新增

- **自动识别动漫头部并加入训练遮罩（#555）**
  在“预处理 → 涂抹”中对当前图片或全部图片运行自动遮罩，可调整置信度、扩边和羽化。识别结果直接进入现有遮罩编辑器，支持笔刷修正、逐图撤销和重做，最后由“保存当前 / 保存全部”落盘；不会修改原图或 caption。识别模型在“设置 → 预处理”统一下载或注册，使用说明见[自动头部遮罩](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/auto-head-mask.md)。

### 变更

- **全站控件、反馈和布局更一致（#528–#545）**
  统一按钮、表单、保存状态、对话框、抽屉、筛选栏和加载反馈，梳理导航、项目入口及工作区滚动。紧凑桌面下优先保留当前任务与主操作，键盘焦点和禁用状态更明确；本次不承诺手机端完整工作流。
- **素材获取与训练集筛选围绕目标操作展开（#559、#560）**
  Booru 下载先估算匹配量再确认下载数，设备文件与服务器文件统一确认导入；筛选页按“未分配素材 → 当前训练分组”组织，验证集作为明确的次级目标，减少误分配。
- **预处理审核与手工编辑更清楚（#551、#552）**
  总览、去重、放大、裁剪和涂抹统一筛选、选中范围与操作反馈；图片区域独立滚动，关键操作保持可见。放大的自定义分辨率有独立输入，裁剪与涂抹保留专业编辑工作区。
- **标签编辑保护本地修改与批量范围（#561）**
  当前文件夹统一约束批量选择和标签分布。收到外部 caption 更新时，必须明确选择保存或放弃再刷新；未实际写入的图片继续保留待保存状态，三栏可拖拽调整。
- **打标与正则集区分“当前任务”和“下一轮设置”（#562）**
  运行中的任务显示已提交快照，表单继续编辑下一轮计划，不再让草稿看起来像当前运行参数。打标默认跳过已有 caption，覆盖需确认；正则集全量重建会提示将删除的现有数据。
- **训练页以安全提交为中心（#564）**
  预设、简单/高级模式与另存入口集中在配置工具栏，右侧可收起的数据 / YAML 预览和摘要辅助检查。离页、换版本、应用预设和入队前都会等待最新草稿保存；失败保留草稿并提供重试。提交冻结配置快照，同版本存在活动任务时可编辑下一轮但不能重复提交。
- **LLM 预设、普通设置和凭证分开保存（#558、#565）**
  LLM 预设各自保存为独立 JSON，内置模板支持本地覆盖；普通设置与 API key 分离，文件写入带原子替换、备份与损坏保护。排队的 LLM 打标任务冻结预设配方，之后编辑或删除预设不会改变已提交任务；凭证缺失会明确失败，不会换用其他 key。
- **LyCORIS 升至 v4.0.0，保留 eager 兼容基线（#548）**
  LoRA / LoHa / LoKr 的配置、保存、加载和续训适配 v4；旧权重的缩放语义保持兼容。不默认启用 Triton、custom backward 或低精度 kernel，也不承诺本次升级带来训练加速。

### 修复

- **标签编辑后旧标签不再从结构化字段中“复活”（#561）**
  完整 JSON caption 经标签编辑器保存后，以用户编辑的扁平标签列表为准，同时保留自然语言描述；简化 LLM JSON 的分类解析不受影响。
- **训练参数输入与草稿保存更可靠（#564）**
  修正输入负号、小数等中间状态被过早覆盖的问题，并防止较早的自动保存响应覆盖较新的编辑。

### 升级提示

- 升级前停止正在运行的任务并关闭 Studio，备份 `studio_data/`；启动器会同步依赖，请等 LyCORIS 安装完成后再训练。使用自建环境时不要保留 `lycoris-lora<4` 的旧热修约束，也不要绕过项目依赖盲目升到更新的上游版本。
- 首次启动会把旧 `secrets.json` 自动迁移到独立设置、凭证和 LLM 预设存储。以后不要再手改旧文件来配置新版；凭证及 legacy 备份仍是本机明文，不能公开分享。回退旧版本前应先备份升级后的完整数据，不能假定兼容投影包含所有新设置。
- 自动遮罩只是未保存编辑，需要手动保存，并在训练配置中启用 masked loss；它与 Leap、NaViT Packing 不兼容，也不会自动删除角色名等 caption 标签。
- 详细步骤与故障处理见 [v0.27 升级说明](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/upgrading-v0.27.md)。
