# 升级到 v0.27

[English](upgrading-v0.27.en.md)

v0.27 调整了配置存储边界、LyCORIS 依赖和工作台交互。功能列表见 [v0.27.0 公告](../announcements/2026-09-11-v0.27.0.md)；本页只说明升级操作和兼容性。

## 升级前

1. 让运行中的训练 / 数据作业结束，或通过队列正常停止；关闭 Studio。不要在运行中的训练进程里替换依赖。
2. 在本机安全位置备份完整 `studio_data/`，并另行备份配置指向该目录之外的数据与训练输出。备份包含凭证，不能发到 issue 或公共网盘。
3. 使用正常更新流程，重新通过 `studio.bat` / `studio.sh` 启动，等待依赖同步完成后再训练。自建环境也应按当前 `requirements.txt` 安装，而不是只拉代码。

## 设置与 LLM 预设迁移

首次启动自动迁移旧 `studio_data/secrets.json`，不需要手动拆文件。新布局如下：

| 路径 | 内容 |
|---|---|
| `studio_data/settings.json` | 非敏感全局设置 |
| `studio_data/credentials.json` | API key / token；本机明文，API 不回读 secret |
| `studio_data/llm_presets/{id}.json` | 独立 LLM 预设或内置模板的本地覆盖；仅引用凭证 ID |
| `studio_data/cache/llm_models/` | 可重新刷新的模型候选缓存，不是预设配方 |
| `studio_data/storage-layout.json` | 迁移状态；只有 `complete` 后新布局才生效 |
| `studio_data/backups/legacy/` | 迁移前旧文件备份，可能含明文凭证 |

迁移后继续在**设置页**修改配置。旧 `secrets.json` 只可能作为给旧版回滚用的兼容投影，**不再是新版配置源**；手改它不会更新新版设置。LLM 预设、普通设置与凭证各走自己的保存接口，普通设置保存不会覆盖整个 LLM 预设列表。

- **并发或损坏提示**：保留当前文件和备份，先停止相关修改。不要通过删除文件、清空内容或手改迁移 marker“修复”。系统会拒绝覆盖无法恢复的数据；预设冲突应重新加载最新版本后再编辑，损坏则应从已知有效备份恢复。
- **排队任务**：LLM 打标在入队时冻结不含 secret 的预设快照，后续修改或删除预设不改变已排队配方。运行时才解析凭证；引用的凭证不存在会明确失败，需要修复凭证后重试，不会自动换 key。
- **分享与备份不同**：分享请使用预设导出，而不是复制整个 `studio_data/`。可移植导出清空本地服务地址和凭证引用；仍应检查自己写在提示词、模型名等配方里的敏感内容。导入后重新配置服务地址和凭证。
- **回退旧版**：先关闭 Studio 并备份升级后的完整目录，再按升级前快照整体恢复对应环境与数据。不要把旧版写回的 `secrets.json` 混进已经完成迁移的新布局，也不要假定兼容投影包含所有新设置。

设计边界见 [ADR 0017](../adr/0017-split-llm-preset-settings-credentials.md)。

## LyCORIS v4

当前项目固定 `lycoris-lora==4.0.0`，使用 **eager** kernel 基线。v0.26.1 热修曾限制 `<4`；升级到本版不应继续保留该限制，也不要自行解除 pin 安装更新的上游版本。

LoRA / LoHa / LoKr 旧权重的缩放语义通过兼容层保留，保存、加载和续训沿用既有入口。本次没有默认启用 Triton、custom backward 或低精度 kernel，也不保证训练加速。第三方训练脚本或自定义 kernel 不在该兼容承诺内。详见 [ADR 0016](../adr/0016-adopt-lycoris-v4-with-safe-kernel-rollout.md)。

## 工作流注意事项

- **打标**默认跳过已有 caption；选覆盖时确认范围。运行中的“当前任务”是提交快照，“下一轮设置”不是实时修改当前任务。
- **训练**入队前先保存最新草稿；保存失败时留在原页重试。同版本存在活动任务时可准备下一轮配置，但不能重复入队。
- **自动头部遮罩**需先在“设置 → 预处理”安装识别模型。结果进入未保存遮罩层，必须“保存当前 / 保存全部”才落盘；训练时还需启用 masked loss，并关闭不兼容的 Leap / NaViT Packing。角色名、发色等 caption 标签不会自动清除。详见[使用指南](auto-head-mask.md)。
