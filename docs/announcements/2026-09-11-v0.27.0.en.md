Workbench workflow upgrade — automatic head masks · safer data editing and training submission · standalone LLM presets · LyCORIS v4 compatibility baseline

### Added

- **Detect anime heads and add them to training masks (#555)**
  Run Auto mask on the current image or all images from Preprocess → Retouch, with confidence, padding, and feather controls. Results enter the existing mask editor as unsaved edits: correct them with the brush, undo or redo per image, then use Save current / Save all to persist them. Source images and captions stay untouched. Download or register recognition models under Settings → Preprocess; see [Automatic head masks](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/auto-head-mask.en.md).

### Changed

- **More consistent controls, feedback, and layouts throughout the app (#528–#545)**
  Buttons, forms, save status, dialogs, drawers, filters, and loading feedback now share common behavior, alongside clearer navigation, project entry points, and workspace scrolling. Compact desktops prioritize the current task and primary actions, with clearer keyboard focus and disabled states. This release does not promise a complete mobile workflow.
- **Acquisition and curation organized around the destination (#559, #560)**
  Booru downloads estimate matches before you confirm a batch size; device and server files share an explicit import confirmation. Curation follows “unassigned sources → current training group,” with the validation set as an explicit secondary destination to reduce accidental assignment.
- **Clearer preprocessing review and manual editing (#551, #552)**
  Overview, deduplication, upscale, crop, and retouch share clearer filters, selection scope, and action feedback. Images scroll independently while important controls stay visible. Custom upscale resolution has its own input, while crop and retouch retain their specialized editing workspaces.
- **Tag editing protects local changes and batch scope (#561)**
  The current folder consistently scopes batch selection and tag distribution. External caption updates require an explicit save-or-discard choice before refresh; images not actually written remain dirty. The three columns can be resized by dragging.
- **Tagging and regularization separate the current job from next-run settings (#562)**
  Running jobs display their submitted snapshot while forms remain available for the next run, rather than making drafts look like live parameters. Tagging defaults to skipping existing captions and confirms overwrites; full regularization rebuilds warn about the existing data they will delete.
- **Training centers on safe submission (#564)**
  Presets, simple/advanced mode, and Save as preset share a configuration toolbar, with a collapsible data / YAML preview and summary for checking the setup. Leaving the page, switching versions, applying a preset, or enqueueing waits for the latest draft to save; failures preserve the draft and offer retry. Submission freezes a config snapshot. An active task for the same version allows next-run editing but blocks duplicate submission.
- **LLM presets, ordinary settings, and credentials are stored separately (#558, #565)**
  Each LLM preset has its own JSON file, and built-in templates support local overrides. Ordinary settings and API keys have separate stores with atomic writes, backups, and corruption protection. Queued LLM tagging jobs freeze their preset recipe, so later preset edits or deletion do not change submitted jobs; a missing credential fails explicitly instead of substituting another key.
- **LyCORIS moves to v4.0.0 with an eager compatibility baseline (#548)**
  LoRA / LoHa / LoKr configuration, saving, loading, and resume paths are adapted to v4 while preserving legacy weight-scaling semantics. Triton, custom backward, and low-precision kernels are not enabled by default, and this upgrade makes no training-speed promise.

### Fixed

- **Deleted tags no longer return from structured caption fields (#561)**
  After TagEdit saves a full JSON caption, the user-edited flat tag list is authoritative while natural-language prose is preserved. Simplified LLM JSON retains its categorized parsing behavior.
- **More reliable training input and draft saving (#564)**
  Intermediate input such as a minus sign or decimal is no longer overwritten too early, and older autosave responses cannot replace newer edits.

### Upgrade notes

- Stop running jobs and close Studio, then back up `studio_data/` before upgrading. Let the launcher finish synchronizing dependencies, including LyCORIS, before training. Custom environments should remove the old `lycoris-lora<4` hotfix constraint, but should not bypass the project's dependency pin to install a newer upstream version.
- First startup automatically migrates legacy `secrets.json` into separate settings, credential, and LLM preset stores. Do not keep editing that old file to configure the new version. Credentials and legacy backups remain plaintext local files and must not be shared publicly. Before rolling back, back up the complete upgraded data; the compatibility projection is not guaranteed to contain every new setting.
- Automatic masks are unsaved edits: save them manually and enable masked loss in training. Masked loss is incompatible with Leap and NaViT Packing. Auto mask does not remove character names or other caption tags.
- See [Upgrading to v0.27](https://github.com/WalkingMeatAxolotl/AnimaLoraStudio/blob/master/docs/user-guide/upgrading-v0.27.en.md) for steps and troubleshooting.
